# Security Policy

## Supported Versions

Only the latest minor version receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `@twin.techies/gst-invoice`, please report it privately by opening a security advisory at:

https://github.com/TwinTricks/gst-invoice/security/advisories/new

**Please do NOT open a public GitHub issue for security vulnerabilities.**

We aim to:
- Acknowledge your report within 48 hours
- Provide a fix or mitigation within 7 days for critical issues
- Coordinate disclosure timing with you

Thank you for helping keep our users safe.
